# Punjab GeoGuardian — Frontend

React dashboard for the [Punjab GeoGuardian](../README.md) project.

**Live:** https://punjab-geoguardian.vercel.app

## Run locally

```bash
npm install
npm start
```

Runs on `http://localhost:3000`. By default, `src/App.js` points to the deployed
production backend — change `API_URL` to `http://127.0.0.1:8000` to test against
a local backend instead.

## Build for production

```bash
npm run build
```

See the [main README](../README.md) for full project documentation, architecture,
methodology, and results.
